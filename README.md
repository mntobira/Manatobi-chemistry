# まなとび化学基礎・化学（Manatobi Chemistry）

大学入学共通テスト対策の『化学基礎』『化学』を、マナトビリスニング・マナトビ英検で磨かれた温かみのあるクリーム紙面UI・とびら君ステージ・4択スピード対戦・暗記帳・通し模試・考察ラボと統合した学習Webアプリケーションです。

## 収録コンテンツ概要

1. **共通テスト形式 分野別演習（全6分野・24単元・48設問＋オリジナルSVG図版7点）**
   - **化学基礎① 物質の構成と結合**（6単元）：純物質と分離・精製、熱運動と加熱曲線、原子構造と同位体・半減期、周期律とイオン化エネルギー、化学結合と結晶4種、分子の極性と水素結合・氷の構造
   - **化学基礎② 物質の変化**（6単元）：物質量molと過不足計算、溶液調製とモル濃度換算（`c = 10pd/M`）、酸・塩基とpH・塩の液性、中和滴定・共洗い・滴定曲線・逆滴定、酸化数・過マンガン酸滴定・ヨウ素滴定、イオン化傾向・ダニエル電池・燃料電池・金属製錬
   - **化学① 理論化学**（4単元）：気体の状態方程式・分圧・蒸気圧、結晶格子と希薄溶液（凝固点降下・浸透圧）、反応エンタルピー（ヘスの法則）と化学平衡（ルシャトリエの原理）、電離平衡・緩衝液・鉛蓄電池・電気分解
   - **化学② 無機物質**（3単元）：非金属元素と工業的製法（接触法・オストワルト法・アンモニアソーダ法）、典型金属と両性元素（Al・Zn・Sn・Pb）、遷移元素・錯イオン・金属イオンの系統分離フロー
   - **化学③ 有機化合物**（3単元）：脂肪族炭化水素（付加・マルコフニコフ則・幾何異性体）、アルコール・アルデヒド・ケトン・エステル・油脂、芳香族化合物の反応経路と分液ロート抽出分離
   - **化学④ 高分子化合物**（2単元）：糖類・アミノ酸（等電点・電気泳動）・タンパク質・核酸、合成繊維（6,6-ナイロン・PET・ビニロン）・合成樹脂・陽イオン交換樹脂の定量計算

2. **共通テスト実戦 通し模試（全3回）**
   - **共通テスト実戦模試『化学基礎』第1回・第2回**（制限時間 30分・50点満点）
   - **共通テスト実戦模試『化学』第1回**（制限時間 60分・100点満点・第1問〜第5問総合）
   - 本番タイマー、解答状況パレット、見直し付箋（★）、配点別自動採点、全選択肢の正誤根拠解説、復習ノート自動連携を搭載。

3. **実験考察・構造決定ラボ（全6テーマ）**
   - 中和滴定の共洗い誤差考察、アンモニア逆滴定の立式、ハーバー・ボッシュ法の温度・圧力条件、陽イオン系統分離、芳香族エステル $\text{C}_9\text{H}_{10}\text{O}_2$ の構造決定、陽イオン交換樹脂による金属イオン定量。
   - 自動下書き保存、文字数メーター、自己点検ルーブリック、模範解答・思考プロセス解説を搭載。

4. **重要用語・化学式・反応式帳 ＆ 双方向4択スピード確認**
   - 6分野 × 3段階（最頻出A・重要B・反応式/法則）＝全18ステージ・105項目（双方向4択 210問）。
   - KaTeX + `mhchem` による化学式・イオン式・可逆反応式の美しい自動組版に対応。

5. **4択スピード対戦（AI・フレンド・全国）・復習ノート・とびら君きせかえ**
   - `chemistry:v1:` ローカルストレージ名前空間および `chem_*` Firestore コレクション接頭辞により、他教科版とデータが混ざらない独立設計。

## 開発・検証・ビルド

```bash
cd eiken-app
npm run generate:materials   # 暗記帳JSON・単元索引の再生成
npm run typecheck            # TypeScript 型検査
npm test                     # Vitest 単体・統合テスト
npm run build                # 省メモリ3段階シーケンシャル本番ビルド (<750MB RAM)
```
