# まなとび化学基礎・化学（Manatobi Chemistry）

大学入学共通テスト『化学基礎』『化学』および国公立2次基礎〜標準までを、**既存問題を1問も消さずに全領域網羅**しつつ、スマートフォンでも1画面で快適に解ける **「マナトビリスニング第6問B式」多資料切替UI** と **「対策プリントの解法鉄則（1行の型）」** を統合した化学学習Webアプリケーションです。

## 主な特徴・収録コンテンツ

### 1. 共通テスト形式 分野別演習（全6分野・143単元・640設問超・オリジナルSVG図版39点）
- **化学基礎① 物質の構成と結合**（22単元）：純物質とクロマトRf/多段抽出、白色粉末定性、同位体・質量分析MS、周期律とイオン化エネルギー、結晶4種、分子極性、多資料統合（電気伝導性×冷却曲線×溶解度）まで網羅。
- **化学基礎② 物質の変化**（25単元）：物質量molと過不足濃度、気体逸散、ワルダー二段階滴定、アンモニア逆滴定（チーム分け）、電導度滴定×pH曲線統合、COD、ダニエル電池・燃料電池・金属腐食まで網羅。
- **化学① 理論化学**（29単元）：状態方程式・蒸気圧・圧縮因子 $Z=PV/(nRT)$、逆浸透、ヘンリーの法則、ヘスの法則、一次反応半減期・アレニウス式、弱酸希釈pH、緩衝液、溶解度積 $K_{\mathrm{sp}}$、直列・並列電気分解、水和物再結晶まで網羅。
- **化学② 無機物質**（25単元）：工業的製法（接触法・オストワルト法・ハーバー法・アンモニアソーダ法・バイヤー法）、ハロゲン・ヨウ素製法、ケイ素・水ガラス、鉄シアノ錯塩、実用合金、過剰試薬による沈殿再溶解グラフ、陽イオン系統分離まで網羅。
- **化学③ 有機化合物**（23単元）：オゾン分解、エステル化平衡 $K=4.0$、環状ラクトン、**5大裏切り者（フェノールエステル＝NaOH 2 mol消費 等）**、芳香族異性体（コルナー法）、分液ロート抽出分離、元素分析×滴定の多段階構造決定まで網羅。
- **化学④ 高分子化合物**（19単元）：糖類・還元性、アミノ酸等電点・イオン交換溶出プロファイル、ペンタペプチド配列決定、微量S分子量、6,6-ナイロン・PET、**ビニロンアセタール化（＋12の鉄則）**、共重合ゴム（SBR/NBR）、イオン交換樹脂の電荷保存連立計算まで網羅。

### 2. スマホ最大化「リスニング第6問B式」1画面多資料切替UI
- **上ペイン（資料デッキ `ChemMaterialDeck`）**：
  - `問題・条件` ／ `データ表（セルタップで ○ → × → 空欄 メモ可）` ／ `図・グラフ（複数枚カルーセル ◀ ▶・スワイプ切替＋タップ ○/× スタンプ＋44px 拡大モーダル）` ／ `会話文` を1行ピルタブで即切り替え。
  - 長いリード文・実験表・複数グラフがある問題でも、縦スクロールで選択肢が見えなくなるストレスを解消。
- **下ペイン（固定小問バー＋全幅4択）**：
  - スクロールしても隠れない `問N 1/k [前の小問] [次の小問]` 固定バーの直下に、現在の小問設問文を全文表示。
  - 左右の矢印余白を撤廃した全幅4択カード（タップ選択 → 再タップ斜線消去）。
- **PC・タブレット**：左ペインに問題冊子＋データ表＋図カルーセル、右ペインに全小問一覧または本番マーク解答用紙を2カラム表示。

### 3. 無駄を省き1問1問丁寧な「プリントの方法」統合解説
- 各設問の解説冒頭に **【プリントの解法鉄則（1行の型）】** を明示：
  - 例：`酸チーム H⁺ mol ＝ 塩基チーム OH⁻ mol`（逆滴定）、`フェノールエステル 1 mol ＝ NaOH 2 mol 消費`（5大裏切り者）、`反応した −OH 1 mol あたり質量 ＋6.0 g`（ビニロン＋12の鉄則）、`n(e⁻) = It / F を全槽共通の1本基準にする`（電気分解）など。
- **段階ステップ解法（1→2→3）** ＋ **数値・単位つきの簡潔な立式プロセス** ＋ **全選択肢①〜④の正誤・ひっかけ根拠** を1問ずつ丁寧に収録。

### 4. 共通テスト実戦 通し模試（全14回：化学基礎7回＋化学7回）
- **『化学基礎』第1回〜第7回**（30分・50点満点・大問2題）
- **『化学』第1回〜第7回**（60分・100点満点・第1問〜第5問総合・全15マーク）
- スマホでは「第6問B式1画面切替ランナー」、PCでは「オフホワイト問題冊子＋マーク解答用紙」2ペインで受験可能。計算メモ帳、見直し付箋（★）、2次余裕合格診断（S〜C判定）、弱点単元ワンタップ直行リンクを搭載。

### 5. 実験考察・構造決定ラボ（全30テーマ）＆ 重要用語・反応式帳（460項目超・双方向4択930問超）
- 記述ルーブリック自己採点つき考察ラボ全30テーマ、赤シート対応の重要用語・半反応式帳、4択スピード確認・全国/AI対戦を搭載。
- `chemistry:v1:` ローカルストレージ名前空間および `chem_*` Firestore コレクション接頭辞により他教科アプリと完全分離。
