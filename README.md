# まなとび化学基礎・化学（Manatobi Chemistry）

大学入学共通テスト『化学基礎』『化学』および国公立2次基礎〜標準までを、**既存問題を1問も消さずに全領域網羅**しつつ、スマートフォンでも1画面で快適に解ける **「マナトビリスニング第6問B式」多資料切替UI**、**「対策プリントの解法鉄則（1行の型）＋赤シート暗記モード」**、および **「センター〜共通テスト37年過去問分析＆本番形式PDF全39冊スタジオ」** を統合した化学学習Webアプリケーションです。

## 主な特徴・収録コンテンツ

### 1. 共通テスト形式 分野別演習（全6分野・155単元・650設問超・オリジナルSVG図版47点）
- **化学基礎① 物質の構成と結合**（24単元）：純物質とクロマトRf/多段抽出、分留と再結晶（微量不純物判定）、同素体SCOPとフラーレン $\mathrm{C_{60}}$（辺90本＝単60＋二重30）、等電子イオン半径（$\mathrm{O^{2-}} > \mathrm{F^-} > \mathrm{Na^+} > \mathrm{Mg^{2+}}$）、同位体・質量分析MS（9:6:1）、周期律とイオン化エネルギー、結晶4種、分子極性まで網羅。
- **化学基礎② 物質の変化**（27単元）：物質量molと過不足濃度、気体逸散、ワルダー二段階滴定、アンモニア逆滴定（チーム分け）、$\mathrm{Ba(OH)_2 + H_2SO_4}$ 電気伝導度V字曲線×pH統合、吸光光度法（ランベルト・ベール検量線×段階希釈）、COD、ダニエル電池・燃料電池・リチウムイオン二次電池（$\pm 7.0\,\mathrm{g/mol\ e^-}$）・金属腐食まで網羅。
- **化学① 理論化学**（31単元）：状態方程式・気液平衡×沸点上昇、圧縮因子 $Z=PV/(nRT)$、逆浸透、ヘンリーの法則、**簡易熱量計の冷却曲線 $t_0$ 外挿（$\Delta T = T_2^* - T_1$）** と結合エネルギー・生成エンタルピー、一次反応半減期・アレニウス式、弱酸存在割合曲線（$\mathrm{pH}=\mathrm{p}K_a$ 交点）、緩衝液、溶解度積 $K_{\mathrm{sp}}$、直列・並列電気分解、水和物再結晶まで網羅。
- **化学② 無機物質**（27単元）：実験室気体発生と**塩素の洗気びん順序（水→濃硫酸）**、**乾燥剤2大例外（$\mathrm{CaCl_2 \times NH_3}$・濃$\mathrm{H_2SO_4 \times H_2S}$）**、$3\mathrm{Cu}+8\mathrm{HNO_3}$ の酸化剤 vs 酸の役割比、工業的製法（接触法・オストワルト法・ハーバー法・アンモニアソーダ法・バイヤー法）、鉄シアノ錯塩、クロム液性平衡×モール法 $K_{\mathrm{sp}}$ 連立、過剰試薬による再溶解グラフ、陽イオン系統分離まで網羅。
- **化学③ 有機化合物**（25単元）：オゾン分解、エステル化平衡 $K=4.0$、環状ラクトン、**5大裏切り者（フェノールエステル＝NaOH 2 mol消費 vs ベンジルエステル＝1 mol消費）**、**アニリンの氷冷ジアゾ化（0〜5℃）・アゾカップリングと芳香族置換の分子量増減即算（ニトロ化＋45・アセチル化＋42・臭素化＋79）**、医薬品多段収率、分液ロート抽出分離、多段階構造決定まで網羅。
- **化学④ 高分子化合物**（21単元）：糖類・還元性、グルタチオン（GSSG 分子量612）、アミノ酸等電点・イオン交換溶出、ペンタペプチド配列決定、酵素反応速度論（$V_{\max}$・$K_m$・競争阻害 vs 非競争阻害）、6,6-ナイロン・PET・ポリ乳酸・ポリイミド（$-2\mathrm{H_2O}$）、**ビニロンアセタール化（＋12の鉄則）**、**強酸性陽イオン交換樹脂の2価混合塩連立定量**、**二本鎖DNAシャルガフ則＆水素結合総数**まで網羅。

### 2. スマホ最大化「リスニング第6問B式」1画面多資料切替UI ＆ 赤シート・PDFまとめプリント
- **演習前1画面「まとめプリント」＋赤シート暗記トグル＋A4まとめPDF**：
  - 各単元の最初に1画面で要点公式・比較表・共通テストの急所を整理。右上の **「赤シート暗記」ボタン** で重要式と表セルを赤マスクして1箇所ずつタップ確認でき、印刷用 **「A4まとめPDF」** もワンタップ表示。
- **上ペイン（資料デッキ `ChemMaterialDeck`）**：
  - `問題・条件` ／ `データ表（セルタップで ○ → × → 空欄 メモ可）` ／ `図・グラフ（複数枚カルーセル ◀ ▶・スワイプ切替＋タップ ○/× スタンプ＋44px 拡大モーダル）` ／ `会話文` を1行ピルタブで即切り替え。
  - 現在解答中の小問が「表」や「図1・図2…」に言及しているときは該当タブに参照ドットを自動点灯し、複数図版カルーセルも該当する図番号へ自動ジャンプ。
- **下ペイン（固定小問バー＋全幅4択）**：
  - スクロールしても隠れない `問N 1/k [前の小問] [次の小問]` 固定バーの直下に、現在の小問設問文を全文表示し、全幅4択カード（タップ選択・斜線消去対応）で解答。

### 3. 全問100%実装・無駄を省き1問1問丁寧な「プリントの方法」統合解説
- 全650超の単元設問および全220超の模試設問すべて（汎用フォールバック0件）に、専用設計された **【プリントの解法鉄則（1行の型）】** と **【2〜3段階ステップ解法】**、および **【全選択肢①〜④の丁寧な正誤・ひっかけ根拠】** を完備。

### 4. 共通テスト実戦 通し模試（全18回：化学基礎9回＋化学9回）＆ 37年過去問分析・全39冊PDFスタジオ
- **『化学基礎』第1回〜第9回**（30分・50点満点・大問2題）
- **『化学』第1回〜第9回**（60分・100点満点・第1問〜第5問総合）
- **センター(1990-2020)〜共通テスト(2021-2026) 37年過去問分析スタジオ**：歴代ひっかけ誤文18選（赤シート＆単元直結）＋模試冊子・A4横マークシート・まとめプリントの全39冊PDFを収録。

### 5. 実験考察・構造決定ラボ（全34テーマ）＆ 重要用語・反応式帳（465項目・双方向4択930問）
- 記述ルーブリック自己採点つき考察ラボ全34テーマ、赤シート対応の重要用語・半反応式帳、4択スピード確認・全国/AI対戦を搭載。
- `chemistry:v1:` ローカルストレージ名前空間および `chem_*` Firestore コレクション接頭辞により他教科アプリと完全分離。
