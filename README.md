# まなとび化学基礎・化学（Manatobi Chemistry）

大学入学共通テスト『化学基礎』『化学』および国公立2次基礎〜標準までを、**既存問題を1問も消さずに全領域網羅**しつつ、スマートフォンでも1画面で快適に解ける **「マナトビリスニング第6問B式」多資料切替＆計算メモUI**、**「対策プリントの解法鉄則（1行の型）＋赤シート暗記モード」**、および **「センター〜共通テスト37年過去問分析（ひっかけ24選）＆本番形式PDF全39冊スタジオ」** を統合した化学学習Webアプリケーションです。

## 主な特徴・収録コンテンツ

### 1. 共通テスト形式 分野別演習（全6分野・161単元・675設問超・オリジナルSVG図版51点）
- **化学基礎① 物質の構成と結合**（25単元）：純物質とクロマトRf/多段抽出、分留と再結晶、同素体SCOPとフラーレン $\mathrm{C_{60}}$（90辺）、等電子イオン半径、配位結合イオン識別（$\mathrm{HCOO^-}$ 除外）、**結晶4種マトリックス（融解 $\mathrm{NaCl}$ vs 液化 $\mathrm{HCl}$）**、最密充填構造（fcc/hcp/bcc 密度立式）まで網羅。
- **化学基礎② 物質の変化**（28単元）：物質量molと過不足濃度、**混合炭化水素の完全燃焼連立計算**、ワルダー二段階滴定、アンモニア逆滴定、$\mathrm{Ba(OH)_2 + H_2SO_4}$ 電気伝導度V字曲線、**硫酸酸性 $\mathrm{KMnO_4}$ 滴定（塩酸・硝酸NG理由と希釈%換算）**、吸光度検量線、リチウムイオン電池・燃料電池まで網羅。
- **化学① 理論化学**（32単元）：**気液平衡ピストン膨張の $P\text{-}V$ 折れ線グラフ（全蒸発境界 $V^*$）**、**硫酸銅(II)五水和物 $\mathrm{CuSO_4\cdot 5H_2O}$ の再結晶1行比例式**、簡易熱量計の冷却曲線 $t_0$ 外挿、結合エネルギー、一次反応・アレニウス式、弱酸存在割合曲線、緩衝液、溶解度積 $K_{\mathrm{sp}}$、直列・並列電気分解まで網羅。
- **化学② 無機物質**（28単元）：塩素発生の洗気びん順序（水→濃硫酸）、乾燥剤2大NG例外、$3\mathrm{Cu}+8\mathrm{HNO_3}$ の酸化剤比、**オストワルト法 $\mathrm{NO}$ 完全循環合算式（$\mathrm{NH_3 : HNO_3 = 1 : 1}$）**、**接触法（$\mathrm{FeS_2 \to 2H_2SO_4}$・濃硫酸吸収理由）**、**ソルベー法の物質収支（$\mathrm{CaCO_3}$ 半減）**、錯塩、陽イオン系統分離まで網羅。
- **化学③ 有機化合物**（26単元）：オゾン分解、初期水ありエステル化平衡、**5大裏切り者（酢酸フェニル 2 mol・酢酸ベンジル 1 mol・アセチルサリチル酸 3 mol）**、氷冷ジアゾ化・アゾカップリング、**油脂のけん化価・ヨウ素価からの分子量＆$\mathrm{C{=}C}$ 二重結合数決定**、セッケン vs 合成洗剤、芳香族抽出分離まで網羅。
- **化学④ 高分子化合物**（22単元）：糖類・グルタチオン、ペプチド配列決定、酵素反応速度論（競争阻害 vs 非競争阻害）、**ビニロン合成「＋12（反応 $-\mathrm{OH}$ $1\,\mathrm{mol}$ あたり $+6.0\,\mathrm{g}$）の鉄則」**、ポリイミド（$-2\mathrm{H_2O}$）、**機能性分離膜（透析・逆浸透・イオン交換膜）**、2価混合塩イオン交換連立、二本鎖DNA水素結合数まで網羅。

### 2. スマホ最大化「リスニング第6問B式」1画面多資料切替UI ＆ 計算メモ・式量早見タブ
- **演習前1画面「まとめプリント」＋赤シート暗記トグル＋A4まとめPDF**
- **上ペイン（資料デッキ `ChemMaterialDeck`）**：
  - `問題・条件` ／ `データ表（セル ○/× メモ可）` ／ `図・グラフ（複数枚カルーセル・図番号自動ジャンプ・○/×スタンプ・44px拡大）` ／ `会話文` に加え、**`計算メモ・式量` タブ**（頻出式量バー＋ワンタップ演算子チップ＋手元メモ欄）を搭載。下の4択を隠さず1画面で立式・計算が完結。
- **スマホ解説画面の即座な振り返り**：
  - 不正解時はスマホでも「プリントの解法鉄則（1行の型）＋正解までのステップ」を最初から自動展開し、正解時も1行鉄則バナーを常時表示。

### 3. 共通テスト実戦 通し模試（全20回：化学基礎10回＋化学10回）＆ 37年過去問分析・全39冊PDFスタジオ
- **『化学基礎』第1回〜第10回**（30分・50点満点・大問2題）
- **『化学』第1回〜第10回**（60分・100点満点・第1問〜第5問総合）
- **センター(1990-2020)〜共通テスト(2021-2026) 37年過去問分析スタジオ**：歴代ひっかけ誤文**24選**（赤シート＆単元直結）＋模試冊子・A4横マークシート・まとめプリントの全39冊PDFを収録。

### 4. 実験考察・構造決定ラボ（全40テーマ）＆ 重要用語・反応式帳（465項目・双方向4択930問）
- 記述ルーブリック自己採点つき考察ラボ**全40テーマ**、赤シート対応の重要用語・半反応式帳、4択スピード確認・全国/AI対戦を搭載。
