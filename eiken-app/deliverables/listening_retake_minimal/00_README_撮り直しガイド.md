# まなとび英検 リスニング品質監査＆最低限撮り直しパッケージ

全8級・全120回（**3,285 音源 ／ 3,465 設問**）を網羅監査し、「全部やり直すとキリがない」という方針に基づき、**本当に作り直し（再収録）が必要な最低限の 199 件（全体の 6.1%）** だけに絞り込んだ差し替え用音源プロンプト一式です。

- **準1級（345件）・1級（315件）は撮り直し 0 件**（全件そのまま本番利用OK）
- **印刷選択肢のみの表記ズレ・品詞不統一（計368箇所）** は、音声の再収録なしでアプリ原本側をすでに修正済みです。

## 収録ファイル一覧
1. `01_必須のみ_撮り直し音源プロンプト_199件.txt`
   - **最優先・これだけ作れば模試破綻ゼロになる必須199件**の統合プロンプト集（冒頭にそのままコピペできるManus/ElevenLabs指示文付き）
2. `per_grade_prompts/retake_prompts_<grade>_<N>items.txt`
   - 級別に分割したプロンプト集（分担作業や級ごとのバッチ投入にそのまま使えます）
     - `eiken_5`（5級）：**1件**
     - `eiken_4`（4級）：**20件**
     - `eiken_3`（3級）：**6件**
     - `eiken_pre2`（準2級）：**6件**
     - `eiken_pre2plus`（準2級プラス）：**87件**（同一回内重複75件＋業種/作物/施設矛盾12件）
     - `eiken_2`（2級）：**79件**（同一回内重複75件＋業種/作物矛盾4件）
3. `retake_minimal_199_list.csv`
   - Excel / スプレッドシートで進捗管理できる一覧表（UTF-8 BOM付き）
4. `manifest_retake_minimal_199.json`
   - 自動生成スクリプトに直接読み込ませられる構造化JSONマニフェスト（新旧台本・設問・選択肢・正解番号・和訳・解説すべて収録。**既存の正解番号 `answerIndex` は1問も変えていません**）
5. `02_任意予備_会話自然化プロンプト_75件.txt`
   - 正解判定や文法には問題ないものの、会話の言い淀みやナレーター二重質問をさらに自然にしたい場合のみ使える予備リスト（やらなくても模試として成立します）

## 納品後の反映方法
MP3ファイル名は既存の `音源ID.mp3`（例：`eiken_pre2plus_listening_r01_part2_11.mp3`）のままZIPで渡していただければ、このマニフェストの新設問・新選択肢と同時にワンコマンドで差し替え統合できます。
